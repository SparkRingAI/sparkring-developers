# Code of conduct / 行为准则

Be respectful, specific, and welcoming. Discuss ideas and evidence. Harassment, discrimination, threats, doxxing, spam, and publication of private information are not acceptable in Issues, Discussions, reviews, or other project spaces.

请友善、具体、尊重他人，围绕观点和证据讨论。Issue、Discussion、评审等社区空间不接受骚扰、歧视、威胁、人肉搜索、垃圾信息或披露私人资料。

Maintainers may edit or hide inappropriate content, lock discussions, remove contributions, or restrict participation according to the severity and repetition of a violation. These rules apply to maintainers as well as contributors.

维护者可根据问题严重程度及重复情况编辑或隐藏不当内容、锁定讨论、移除贡献或限制参与。维护者同样遵守本准则。

Report abuse through GitHub's **Report content** or **Report abuse** controls. Do not start a public thread containing another person's private details. For security vulnerabilities or credential disclosure, use [Security](SECURITY.md) instead.

可使用 GitHub 的 **Report content / Report abuse** 功能报告不当行为。不要新开公开讨论披露他人私人信息。漏洞或凭据泄露请使用[安全报告](SECURITY.md)。
