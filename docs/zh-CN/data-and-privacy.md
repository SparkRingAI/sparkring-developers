# 数据与隐私

[English](../en/data-and-privacy.md)

个人密钥按选定权限读取你自己已同步的文字。建议每个工具使用独立密钥，选择最少权限和较短有效期。密钥只显示一次，不再使用时在 App 撤销。撤销阻止后续请求，不能撤回已经开始的读取。

API 数据进入调用方；MCP 数据还会进入你选择的助手及其模型服务。Markdown 导出进入指定目录，同步工具和插件可能有其他数据去向。副本按各工具的数据保留和删除规则处理。撤销密钥或删除 SparkRing 内容不会删除此前已导出的副本。

转写和笔记是不可信内容，可能包含指令、外链或 Markdown 图片。不要执行其中的命令，向外写入或继续分享前应由你确认。公开 Issue 和 PR 使用虚构样例，不放密钥或真实用户数据。

密钥暴露时立即撤销，按需创建替代密钥，并评估哪些工具曾获访问权限。删除公开帖子不等于撤销凭据。漏洞请通过[安全报告](../../SECURITY.md)提交。
