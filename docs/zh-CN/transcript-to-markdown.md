# 转写 → Markdown / Obsidian

[English](../en/transcript-to-markdown.md) · [全部文档](../README.md)

状态：手动教程，由维护者编写。无需 API、自动化、账号关联或插件。

## 前提与数据去向

使用任意文字编辑器；如果已使用 Obsidian，也可选择现有 vault。先用[虚构转写](../../examples/fictional-transcript.txt)体验。以后使用自己的内容时，需要 App 版本支持对已有完整转写的录音执行 **复制转写**。

数据路径：**SparkRing → 系统剪贴板 → 你选择的笔记或 vault**。使用虚构样本时，起点是本仓库。剪贴板、编辑器、vault 是独立存储位置。云同步 vault、剪贴板历史和跨设备剪贴板可能产生额外副本；使用个人内容前先检查相关设置。

## 步骤

1. 打开样本，复制三行说话人文字。使用自己的录音时，打开录音详情，选择 **… → 复制转写**，粘贴后先检查文字，再决定是否继续分享。复制内容可能是界面显示的精简稿，不保证是逐字原文。
2. 在文字编辑器中新建 `garden-meetup.md`，或在所选 Obsidian vault 新建笔记。
3. 加入标题 `# Garden meetup` 和小节 `## Transcript`，将三行文字粘贴到下面，保留说话人标签。
4. 加入 `## Action items`，手动记录文字中有依据的任务：Speaker 1 起草邀请，Speaker 2 检查种子清单。原文没有日期，不填写日期。
5. 保存并重新打开笔记，与[示例结果](../../examples/fictional-note.md)对照。使用 Obsidian 时，进入阅读视图检查标题和清单。

## 验证与恢复

- 三行说话人文字应与样本一致，归属正确。
- 应有两项未完成任务，不新增日期或参与者姓名。
- 本地编辑器即可完成样本步骤；这些步骤无需向 SparkRing 或其他服务发送请求。
- 如没有 **复制转写** 或入口不可用，检查是否已有可见转写及 App 版本。继续使用样本，不提取 App 凭据或调用未公开接口。
- 如格式丢失，使用纯文本粘贴。如目标自动同步，使用对应服务的功能移除不需要的副本。

删除源录音不会删除笔记、剪贴板历史、同步副本或备份，需要分别管理。公开贡献只使用虚构示例。
